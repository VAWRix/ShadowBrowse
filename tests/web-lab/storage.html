How to Verify with ShadowBrowse

  1. Start an Anonymous Session in ShadowBrowse.
  2. Click Write Test Identifiers on this page.
  3. Check the Autopsy tab in Side Panel — storage keys will be detected.
  4. Click END ANONYMOUS SESSION in ShadowBrowse popup.
  5. Reload this page and click Read Storage State: cookies and local storage should be purged.
